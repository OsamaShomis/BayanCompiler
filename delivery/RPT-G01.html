1. وصف المشروع والمعمارية والبيئة التقنية

1.1 فكرة المشروع ونظرة عامة

مشروع لغة بيان (Bayan) هو نظام حاسوبي متكامل صُمم لتقديم لغة برمجة عربية عالية المستوى، مدعومة بمترجم مستقل مبني بالكامل من الصفر (From Scratch) ومحرر تفاعلي حديث يحاكي واجهة وتجربة المستخدم لبرنامج Visual Studio Code، مع دعم كامل وأصيل لاتجاه الكتابة والواجهة من اليمين إلى اليسار (RTL).

المعمارية المستقلة المنفصلة (Decoupled Architecture):
المحرر المرئي والمترجم هما برنامجان تنفيذيان منفصلان تماماً. عند النقر على تشغيل أو ترجمة، يقوم المحرر باستدعاء المترجم المستقل (BayanCompiler.exe) عبر سطر الأوامر (CLI Inter-process Communication) وتمرير مسار الملف، ثم قراءة وتحليل النتائج وعرضها في تبويبات مخصصة.

1.2 لغات البرمجة ومنصة التشغيل

  • لغة البرمجة الأساسية: C# (الإصدار C# 10.0 الحديث).
  • بيئة ومنصة التشغيل: Microsoft .NET 6.0 LTS (الإصدار 6.0.100).

2. الشرح التخصصي لمراحل المترجم وهياكل البيانات

2.1 التحليل المعجمي (Lexer.cs)

يقوم المحلل المعجمي بقراءة الملف المصدري حرفاً بحرف وتحويله إلى قائمة متتابعة من الرموز (Tokens). يتعرف المحلل على الكلمات المفتاحية العربية (ثابت، متغير، اذا، والا، طالما، كرر، اطبع)، المعرفات، الأرقام الصحيحة والعشرية، النصوص، والمعاملات الحسابية والمنطقية.

  • المدخلات: النص المصدري بترميز UTF-8.
  • المخرجات: قائمة كائنات List<Token> مع توثيق السطر والعمود.
  • هياكل البيانات: TokenType Enum, Token Class, وقاموس الكلمات المحجوزة Dictionary<string, TokenType>.
// جزء من كود التحليل المعجمي ومطابقة الرموز
if (char.IsLetter(c) || c == '_')
{
    int startCol = col;
    string lexeme = ReadIdentifier(sourceCode, ref index, ref col);
    TokenType type = Keywords.TryGetValue(lexeme, out var kw) ? kw : TokenType.IDENTIFIER;
    tokens.Add(new Token(type, lexeme, line, startCol));
    continue;
}

2.2 التحليل النحوي التنبؤي وشجرة الإعراب (Parser.cs & AstNodes.cs)

يطبق المحلل النحوي خوارزمية التحليل التنبؤي الصارم $LL(1)$ الخالي من التراجع، مع ضمان خلو القواعد من اللف العودي اليساري، ويقوم ببناء شجرة الإعراب المجردة كشجرة كائنية متدرجة (ProgramNode -> StatementNode -> ExpressionNode). 

// التحليل النحوي للتعبيرات وبناء عقد العمليات الحسابية
private ExpressionNode ParseExpression()
{
    ExpressionNode left = ParseTerm();
    while (CurrentToken.Type == TokenType.OP_PLUS || CurrentToken.Type == TokenType.OP_MINUS)
    {
        Token op = ConsumeToken();
        ExpressionNode right = ParseTerm();
        left = new BinaryOpNode(op.Lexeme, left, right, op.Line, op.Column);
    }
    return left;
}

2.3 التحليل الدلالي وجدول الرموز (SemanticAnalyzer.cs & SymbolTable.cs)

يقوم المحلل الدلالي بزيارة شجرة الإعراب، وتطبيق القواعد المنطقية للغة: التأكد من التصريح المسبق عن المتغيرات، منع التعديل على الثوابت، التحقق من توافق أنواع البيانات، وعزل مجالات الرؤية (Scopes) في هيكل هرمي متعدد المستويات.

2.4 الشفرة الوسيطة ثلاثية العناوين (TacGenerator.cs)

توليد تعليمات TAC الخطية المكونة من معاملات رباعية (Operator, Arg1, Arg2, Result) باستخدام سجلات وسيطة مؤقتة ($t0, $t1, ...) وعناوين قفز شرطية وغير شرطية (Labels).

2.5 توليد كود التجميع الهدفي x86 ومولد PE EXE (AssemblyGenerator.cs & CilGenerator.cs)

يقوم المترجم بتوليد شفرة أسمبلي x86 متوافقة مع NASM/MASM لإثبات الفهم النظري لمعمارية المعالجات وسجلات EAX وEBX وإطار المكدس، وفي الوقت ذاته يولد كود CIL ليتم تجميعه عبر ilasm.exe إلى ملف تنفيذي حقيقي ومستقل program.exe.
