# المرحلة الجديدة: توليد MIPS Assembly وتشغيله في MARS

## المسار الرسمي للمترجم

بعد هذه المرحلة، يصبح خط الترجمة الرسمي للغة «بيان» كما يلي:

```text
ملف .bayan
    ↓
Lexical Analysis
    ↓
Parsing وAST
    ↓
Semantic Analysis
    ↓
Three-Address IR
    ↓
MIPS Code Generator
    ↓
GeneratedProgram.asm
    ↓
MARS
```

لم يعد زر التوليد ينفذ AST مباشرة. المفسر `Interpreter` يبقى في المشروع كنسخة احتياطية وتعليمية، لكن مسار العرض للدكتور هو **IR ثم MIPS Assembly**.

## عناصر الواجهة الجديدة

| العنصر | وظيفته |
|---|---|
| زر `توليد MIPS` | يشغل Lexer ثم Parser ثم Semantic Analyzer ثم IR ثم مولد MIPS. |
| تبويب `IR` | يعرض Three-Address Code قبل تحويله إلى Assembly. |
| تبويب `MIPS Assembly` | يعرض كود MIPS المتوافق مع MARS. |
| زر `حفظ ASM` | يحفظ الكود في ملف بامتداد `.asm`. |
| تبويب `الأخطاء` | يعرض أخطاء التحليل أو قيود مولد MIPS بصيغ `MIPS001` إلى `MIPS003`. |

## نطاق الإصدار الأول من مولد MIPS

| الخاصية | الحالة |
|---|---|
| متغيرات `عدد` | مدعومة باستخدام `.word` و`lw` و`sw`. |
| متغيرات `منطقي` | مدعومة بالقيم `0` و`1`. |
| الأعداد الصحيحة | مدعومة. |
| الجمع والطرح والضرب والقسمة والباقي | مدعومة. |
| المقارنات | مدعومة باستخدام تعليمات مثل `slt` و`seq` و`sne`. |
| `إذا` و`وإلا` | مدعومة باستخدام العلامات والفروع. |
| `طالما` | مدعومة باستخدام علامة بداية و`beq` و`j`. |
| طباعة الأعداد | مدعومة عبر `syscall 1`. |
| طباعة النصوص الثابتة | مدعومة عبر `.asciiz` و`syscall 4`. |
| النصوص المتغيرة أو دمج النصوص | خارج نطاق الإصدار الأول. |
| النوع `حقيقي` | خارج نطاق الإصدار الأول؛ يحتاج سجلات فاصلة عائمة وإجراءات طباعة خاصة. |

## توليد ملف ASM

1. شغّل مشروع Windows Forms في Visual Studio 2022.
2. افتح ملف اختبار، والأفضل أولاً:

```text
samples/07_sum_execution.bayan
```

3. اضغط زر **توليد MIPS**.
4. تأكد من أن تبويب **الأخطاء** فارغ.
5. افتح تبويب **IR** وتأكد من ظهور متغيرات مثل `var_0` وقيم مؤقتة مثل `temp_0` وعلامات للحلقة.
6. افتح تبويب **MIPS Assembly** وتأكد من ظهور القسمين `.data` و`.text` ووسم `main:`.
7. اضغط **حفظ ASM** واحفظ الملف باسم مثل:

```text
GeneratedProgram.asm
```

## تشغيل الملف في MARS

1. حمّل محاكي MARS وافتحه.
2. من قائمة **File** اختر **Open** ثم اختر `GeneratedProgram.asm`.
3. اختر **Run → Assemble** أو اضغط `F3`.
4. اختر **Run → Go** أو اضغط `F5`.
5. راقب نافذة **Run I/O**.

عند تشغيل `07_sum_execution.bayan`، النتيجة المتوقعة هي:

```text
15
```

## مثال صغير

### برنامج بيان

```بيان
برنامج تجربة
    دع س : عدد = 5؛
    إذا (س > 3) {
        اطبع("القيمة كبيرة")؛
    }
نهاية
```

### IR مختصرة

```text
var var_0 : Int
var temp_0 : Bool

var_0 = 5
temp_0 = var_0 > 3
ifZero temp_0 goto else_0
print_string &str_0
else_0:
```

### أجزاء MIPS المتوقعة

```asm
.data
var_0: .word 0
str_0: .asciiz "القيمة كبيرة"
newline: .byte 10, 0

.text
.globl main
main:
    li $t0, 5
    sw $t0, var_0
    lw $t0, var_0
    li $t1, 3
    slt $t2, $t1, $t0
    sw $t2, temp_0
    lw $t0, temp_0
    beq $t0, $zero, else_0
    la $a0, str_0
    li $v0, 4
    syscall
else_0:
    li $v0, 10
    syscall
```

## رموز أخطاء مولد MIPS

| الرمز | المعنى |
|---|---|
| `MIPS001` | عقدة أو نوع أو متغير لا يستطيع مولد MIPS الحالي تحويله. |
| `MIPS002` | استخدام نوع خارج نطاق الإصدار الأول، مثل `حقيقي` أو متغير `نص`. |
| `MIPS003` | استخدام عملية نصية غير مدعومة، مثل جمع نصين. |
| `MIPS999` | خطأ غير متوقع أثناء التوليد؛ يجب إرسال الرسالة كاملة للمراجعة. |

## ما يقال للدكتور

> ينفذ المشروع المراحل الأمامية: التحليل اللغوي والتحليل النحوي وبناء AST والتحليل الدلالي. بعد ذلك يحول AST إلى Three-Address IR، ثم يولد ملف MIPS Assembly متوافقاً مع محاكي MARS. يدعم الإصدار الأول الأعداد الصحيحة والمنطقيات والتحكم الشرطي والحلقات والطباعة، وتعد الأنواع الحقيقية والعمليات النصية توسعات مستقبلية.
