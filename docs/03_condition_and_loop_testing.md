# اختبار المرحلة الثالثة: الإسناد والشرط والحلقة

## ما الذي أضيف في هذه النسخة؟

يدعم `Parser` الآن التعليمات التالية في لغة بيان:

| الصياغة | الغرض |
|---|---|
| `س ← س + 1؛` | إسناد قيمة جديدة إلى متغير. |
| `إذا (شرط) { ... }` | تنفيذ كتلة عند تحقق الشرط. |
| `وإلا { ... }` | تنفيذ كتلة بديلة عند عدم تحقق الشرط. |
| `طالما (شرط) { ... }` | تكرار كتلة ما دام الشرط صحيحاً. |
| `< <= > >= == !=` | عمليات المقارنة. |
| `&& || !` | العمليات المنطقية. |

لا تنفذ هذه النسخة البرنامج بعد؛ إنها **تقرأه وتبني AST فقط**. التنفيذ الفعلي سيكون في Interpreter بعد التحليل الدلالي.

## تشغيل النسخة الجديدة

1. فك ضغط الحزمة الجديدة في مجلد جديد بجانب النسخ السابقة.
2. افتح في Visual Studio 2022 الملف:

```text
BayanCompiler\src\BayanCompiler\BayanCompiler.csproj
```

3. اضغط `Ctrl + Shift + B`.
4. عند ظهور `Build succeeded`، اضغط `F5`.

## اختبار الشرط: الملف 01

1. اضغط **فتح ملف**.
2. افتح:

```text
samples\01_valid_program.bayan
```

3. اضغط **تحليل البرنامج**.
4. افتح تبويب `Tokens / AST`.

يجب أن يظهر نص يحتوي على العقد التالية:

```text
ProgramNode: تجربة
VarDeclarationNode: س : عدد
IfNode:
Condition:
BinaryExpressionNode: Greater
Then:
BlockNode:
PrintNode:
Else:
BlockNode:
PrintNode:
```

يجب أن يبقى تبويب **الأخطاء** فارغاً.

## اختبار الحلقة والإسناد: الملف 02

1. افتح:

```text
samples\02_loop_and_sum.bayan
```

2. اضغط **تحليل البرنامج**.
3. افتح تبويب `Tokens / AST`.

يجب أن يظهر نص يحتوي على العقد التالية:

```text
ProgramNode: مجموع
VarDeclarationNode: س : عدد
VarDeclarationNode: مجموع : عدد
WhileNode:
Condition:
BinaryExpressionNode: LessEqual
Body:
BlockNode:
AssignmentNode: مجموع
AssignmentNode: س
IfNode:
BinaryExpressionNode: EqualEqual
```

يجب ألا تظهر أخطاء في تبويب **الأخطاء**.

## اختبار خطأ نحوي: الملف 04

1. افتح:

```text
samples\04_syntax_error.bayan
```

2. اضغط **تحليل البرنامج**.
3. افتح تبويب **الأخطاء**.

النتيجة المتوقعة رسالة تبدأ هكذا:

```text
[SYN001] ... متوقع الرمز "؛" بعد تعريف المتغير.
```

## ما الذي لم ينفذ بعد؟

| المرحلة التالية | النتيجة التي ستضيفها |
|---|---|
| `SemanticAnalyzer` | كشف استخدام متغير غير معرّف وعدم توافق الأنواع. |
| `Interpreter` | تنفيذ `اطبع` والحسابات والشروط والحلقات فعلياً. |
| التحسينات | تلوين الكود، أرقام الأسطر، واسترداد أفضل من الأخطاء. |

مثال الملف `05_semantic_error.bayan` لا يعطي خطأ حالياً من Parser، لأن مشكلة `مجموع غير معرّف` ليست خطأ نحوياً؛ ستظهر بعد تنفيذ التحليل الدلالي.
