# مواصفات لغة «بيان» — الإصدار 1.0

**اسم المشروع:** مترجم لغة برمجة عربية مبسطة باستخدام C#  
**اسم اللغة:** بيان  
**حالة الوثيقة:** مواصفات الإصدار الأساسي المعتمدة قبل بدء التنفيذ

> لغة «بيان» لغة تعليمية صغيرة. هدفها إظهار مراحل المترجم كاملة: التحليل اللغوي، والتحليل النحوي، والتحليل الدلالي، ثم التنفيذ. لا تهدف إلى أن تكون بديلاً كاملاً للغات البرمجة الصناعية.

## 1. نطاق الإصدار الأساسي

يدعم هذا الإصدار تعريف المتغيرات، والإسناد، والطباعة، والعبارات الشرطية، والحلقات، والتعابير الحسابية والمنطقية. لا يدعم هذا الإصدار الدوال أو المصفوفات أو الكائنات أو النطاقات المتداخلة أو الإدخال من المستخدم. هذه الخصائص يمكن إضافتها لاحقاً بعد نجاح المترجم الأساسي.

| المجال | المدعوم في الإصدار 1.0 | غير المدعوم حالياً |
|---|---|---|
| أنواع البيانات | `عدد`، `حقيقي`، `منطقي`، `نص` | مصفوفات، كائنات، أنواع مركبة. |
| العبارات | تعريف، إسناد، طباعة، شرط، حلقة `طالما` | دوال، إرجاع، إدخال، استثناءات. |
| النطاق | نطاق عام واحد | نطاقات الكتل والدوال. |
| الثوابت العددية | أرقام لاتينية مثل `0` و`125` و`3.14` | الأرقام العربية مثل `١٢٣`. |
| النصوص | بين علامتي اقتباس مزدوجتين | سلاسل متعددة الأسطر أو محارف مهربة. |

## 2. قواعد الملف المصدر

تحفظ برامج «بيان» بامتداد `.bayan` وبترميز UTF-8. تقبل اللغة الكلمات المحجوزة والمعرفات العربية. تستخدم اللغة `؛` فاصلة منقوطة عربية لإنهاء التعليمات، على أن يقبل المترجم أيضاً `;` اللاتينية كبديل عملي.

التعليق يبدأ بالرمزين `//` وينتهي عند نهاية السطر. لا يؤثر التعليق في تنفيذ البرنامج.

```بيان
// هذا تعليق
دع س : عدد = 5؛
```

## 3. الكلمات المحجوزة

لا يجوز استخدام الكلمات الآتية بوصفها أسماء متغيرات:

| الكلمة | المعنى |
|---|---|
| `برنامج` | بداية البرنامج. |
| `نهاية` | نهاية البرنامج. |
| `دع` | تعريف متغير جديد. |
| `إذا` | بداية شرط. |
| `وإلا` | الفرع البديل للشرط. |
| `طالما` | بداية حلقة تكرار. |
| `اطبع` | طباعة قيمة أو نص. |
| `عدد` | نوع عدد صحيح. |
| `حقيقي` | نوع عدد عشري. |
| `منطقي` | نوع منطقي. |
| `نص` | نوع نصي. |
| `صحيح` | القيمة المنطقية true. |
| `خطأ` | القيمة المنطقية false. |

## 4. المعرفات والمتغيرات

اسم المتغير يبدأ بحرف عربي أو `_`، ثم يمكن أن يحتوي حروفاً عربية أو أرقاماً لاتينية أو `_`. تعامل اللغة الأسماء حرفياً؛ لذلك `أحمد` و`احمد` اسمان مختلفان.

| المثال | الحالة | السبب |
|---|---|---|
| `س` | صحيح | حرف عربي. |
| `قيمة_نهائية2` | صحيح | حروف عربية و`_` ورقم لاتيني. |
| `_عداد` | صحيح | يبدأ بـ`_`. |
| `2س` | خطأ | يبدأ برقم. |
| `دع` | خطأ | كلمة محجوزة. |
| `قِيمة` | غير مدعوم في 1.0 | يحتوي تشكيلاً؛ يرفض بوضوح. |

## 5. أنواع البيانات والقيم

| النوع | الكلمة | أمثلة للقيم | القيمة الافتراضية عند عدم التهيئة |
|---|---|---|---|
| عدد صحيح | `عدد` | `0`، `25`، `-8` | `0` |
| عدد عشري | `حقيقي` | `3.14`، `0.5` | `0.0` |
| منطقي | `منطقي` | `صحيح`، `خطأ` | `خطأ` |
| نص | `نص` | `"مرحبا"` | `""` |

يسمح بتحويل ضمني من `عدد` إلى `حقيقي` فقط. لا يسمح بتحويل `حقيقي` إلى `عدد`، ولا بتحويل النصوص أو المنطقيات إلى أعداد.

## 6. التعريف والإسناد

تعريف المتغير يصرح بالاسم والنوع، ويمكن أن يتضمن قيمة ابتدائية.

```بيان
دع عمر : عدد = 20؛
دع معدل : حقيقي = 95.5؛
دع مكتمل : منطقي = صحيح؛
دع رسالة : نص = "مرحباً"؛
دع عداد : عدد؛
```

الإسناد يحدث قيمة متغير موجود سابقاً. يقبل السهم `←` بوصفه الشكل الرسمي، ويقبل `=` شكلاً بديلاً.

```بيان
عداد ← 1؛
عداد = عداد + 1؛
```

لا يسمح بتعريف الاسم نفسه مرتين، ولا بالإسناد إلى متغير غير معرّف، ولا بإسناد قيمة ذات نوع غير متوافق.

## 7. العمليات والتعابير

| المجموعة | العمليات | أنواع المدخلات | الناتج |
|---|---|---|---|
| حسابية | `+`، `-`، `*`، `/`، `%` | `عدد` أو `حقيقي` | عدد أو حقيقي. |
| نصية | `+` | `نص` مع `نص` | نص مدموج. |
| مقارنة | `<`، `<=`، `>`، `>=` | أعداد | منطقي. |
| مساواة | `==`، `!=` | نوعان متوافقان | منطقي. |
| منطقية | `&&`، `||`، `!` | منطقي | منطقي. |

أولوية العمليات من الأعلى إلى الأدنى هي: الأقواس، الأحادي `!` و`-`، الضرب والقسمة والباقي، الجمع والطرح، المقارنات، المساواة، ثم `&&`، ثم `||`.

```بيان
دع نتيجة : عدد = 2 + 3 * 4؛
دع اختبار : منطقي = نتيجة == 14 && صحيح؛
دع تحية : نص = "أهلاً " + "بكم"؛
```

## 8. الطباعة

تطبع التعليمة `اطبع` قيمة تعبير واحد، وتقبل جميع أنواع البيانات.

```بيان
اطبع("النتيجة هي:")؛
اطبع(15)؛
اطبع(صحيح)؛
```

## 9. العبارات الشرطية

يجب أن يكون شرط `إذا` من النوع `منطقي`. كتلة التعليمات توضع بين `{` و`}`. الفرع `وإلا` اختياري.

```بيان
إذا (عمر >= 18) {
    اطبع("مسموح")؛
} وإلا {
    اطبع("غير مسموح")؛
}
```

## 10. حلقة طالما

تكرر `طالما` كتلتها ما دام الشرط المنطقي صحيحاً.

```بيان
دع س : عدد = 1؛
طالما (س <= 5) {
    اطبع(س)؛
    س ← س + 1؛
}
```

## 11. البنية الكاملة للبرنامج

كل ملف برنامج صحيح يبدأ بـ`برنامج` متبوعاً باسم البرنامج، وينتهي بـ`نهاية`.

```بيان
برنامج تجربة
    دع س : عدد = 5؛

    إذا (س > 3) {
        اطبع("القيمة كبيرة")؛
    } وإلا {
        اطبع("القيمة صغيرة أو تساوي 3")؛
    }
نهاية
```

## 12. القواعد النحوية المختصرة (EBNF)

```ebnf
البرنامج        ::= "برنامج" معرف { التعليمة } "نهاية" EOF ;
التعليمة        ::= تعريف | إسناد | طباعة | شرط | تكرار | كتلة ;
تعريف           ::= "دع" معرف ":" النوع [ "=" التعبير ] "؛" ;
النوع           ::= "عدد" | "حقيقي" | "منطقي" | "نص" ;
إسناد           ::= معرف ( "←" | "=" ) التعبير "؛" ;
طباعة           ::= "اطبع" "(" التعبير ")" "؛" ;
شرط             ::= "إذا" "(" التعبير ")" كتلة [ "وإلا" كتلة ] ;
تكرار           ::= "طالما" "(" التعبير ")" كتلة ;
كتلة            ::= "{" { التعليمة } "}" ;

التعبير         ::= منطق_أو ;
منطق_أو         ::= منطق_و { "||" منطق_و } ;
منطق_و          ::= مساواة { "&&" مساواة } ;
مساواة          ::= مقارنة { ( "==" | "!=" ) مقارنة } ;
مقارنة          ::= جمع { ( "<" | "<=" | ">" | ">=" ) جمع } ;
جمع             ::= ضرب { ( "+" | "-" ) ضرب } ;
ضرب             ::= أحادي { ( "*" | "/" | "%" ) أحادي } ;
أحادي           ::= ( "!" | "-" ) أحادي | أولي ;
أولي            ::= عدد_صحيح | عدد_حقيقي | نص | "صحيح" | "خطأ" | معرف | "(" التعبير ")" ;
```

## 13. الأخطاء التي يجب أن يكتشفها المترجم

| المرحلة | رمز مقترح | مثال |
|---|---|---|
| لغوية | `LEX001` | حرف غير مسموح مثل `@`. |
| لغوية | `LEX002` | سلسلة نصية غير مغلقة. |
| نحوية | `SYN001` | فقدان `؛` بعد التعريف. |
| نحوية | `SYN002` | قوس أو قوس معقوف غير مغلق. |
| دلالية | `SEM001` | استخدام متغير قبل تعريفه. |
| دلالية | `SEM002` | إعادة تعريف متغير. |
| دلالية | `SEM003` | عدم توافق نوع الإسناد. |
| تنفيذ | `RUN001` | قسمة على صفر. |

تتبع كل رسالة خطأ الصيغة الآتية:

```text
[المرحلة:الرمز] سطر X، عمود Y: وصف عربي واضح للخطأ.
```

## 14. قرار الفريق قبل المرحلة التالية

بعد قراءة هذه الوثيقة، يجب أن يعتمد الفريق هذه القرارات دون تغيير أثناء بناء المحلل اللغوي. أي ميزة جديدة، مثل الدوال أو الإدخال أو المصفوفات، تسجل في قائمة تطوير لاحقة ولا تضاف إلى الإصدار الأساسي قبل نجاح جميع الاختبارات الأساسية.

## 15. تحويل Grammar إلى Table-Driven LL(1)

بناءً على متطلبات المقرر، يستخدم التطبيق محلل `Ll1Parser` القائم على Stack وجدول تحليل LL(1). لا يقرأ المحلل النص الخام؛ بل يستقبل قائمة Tokens من Lexer، ويختار إنتاج Grammar من الخلية `M[NonTerminal, Lookahead]`، ثم يبني Concrete Parse Tree قبل تحويلها إلى AST في مرور مستقل.

توجد Grammar بصيغة BNF، ومجموعات FIRST وFOLLOW، وخلايا جدول التحليل غير الفارغة في الوثيقة التالية:

```text
docs/LL1_Grammar_FIRST_FOLLOW.md
```

حُولت التكرارات والاختيارات في قواعد EBNF في القسم 12 إلى Non-terminals لاحقة مثل `StatementList` و`InitializerOpt` و`ElsePart` و`OrTail` و`MultiplicationTail`. الهدف من ذلك إزالة التكرار اليساري وتحديد إنتاج واحد فقط لكل زوج من Non-terminal وLookahead.
