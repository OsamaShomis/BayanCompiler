# تحسين واجهة مترجم بيان من ناحية UI/UX

## الهدف

تمت إعادة تنظيم واجهة Windows Forms لتصبح أوضح في الاستخدام والعرض الأكاديمي، مع الحفاظ على خط المترجم نفسه:

```text
لغة بيان → Lexer → Parser / AST → Semantic Analyzer → IR → MIPS Assembly
```

## أهم التحسينات

| العنصر | التحسين |
|---|---|
| رأس الصفحة | إضافة عنوان واضح ووصف مختصر يوضح أن الهدف هو MIPS Assembly. |
| شريط الأدوات | ترتيب الأوامر وفق سير العمل: فتح، حفظ، Tokens، تحليل، توليد MIPS، حفظ ASM. |
| مساحة العمل | تقسيم مرن بين محرر المصدر ونتائج المراحل، مع مسافات داخلية وحدود خفيفة. |
| محرر المصدر | خط أوضح، خلفية بيضاء، وإيقاف تمييز الروابط غير المفيدة في كود اللغة. |
| تبويبات النتائج | فصل Tokens/AST وIR وMIPS Assembly والأخطاء، مع عناوين أكثر وصفاً. |
| اتجاه النص | عرض لغة بيان وIR بالعربية، وعرض MIPS من اليسار إلى اليمين لأن ذلك أقرب لطبيعة Assembly. |
| حالات الفراغ | تظهر رسالة إرشادية داخل كل تبويب بدلاً من مساحة بيضاء غير مفهومة. |
| التفاعل | تنتقل الواجهة تلقائياً إلى التبويب المناسب بعد تنفيذ التحليل أو التوليد أو عند وجود خطأ. |
| شريط الحالة | يوضح حالة العملية والهدف الحالي `MIPS / MARS` دائماً. |

## تصميم عرض IR

يبدأ تبويب IR بعنوان ثنائي اللغة، ثم يعرض خريطة الأسماء، ثم تعريفات التخزين، ثم التعليمات:

```text
# Three-Address IR — التمثيل الوسيط ثلاثي العناوين

خريطة الأسماء:
  س      → var_0
  مجموع  → var_1

س [var_0] : عدد
مجموع [var_1] : عدد
مؤقت_0 [temp_0] : منطقي

س = 1
مجموع = 0
حلقة_0:
مؤقت_0 = س <= 5
إذا كان مؤقت_0 = 0 اذهب إلى نهاية_الحلقة_1
مؤقت_1 = مجموع + س
مجموع = مؤقت_1
اطبع_عدد مجموع
```

تظهر الأسماء العربية للمستخدم، بينما تبقى الأسماء الداخلية مثل `var_0` و`temp_0` واضحة داخل خريطة الأسماء. يستخدم مولد MIPS الأسماء الداخلية فقط، وبالتالي لا تتأثر قابلية تشغيل ملف Assembly.

## سيناريو اختبار تجربة المستخدم

1. يبدأ المستخدم من محرر المصدر ويجد برنامجاً نموذجياً جاهزاً.
2. يضغط `عرض Tokens` فتنتقل الواجهة إلى تبويب Tokens/AST.
3. يضغط `تحليل البرنامج` فتظهر AST عند النجاح، أو ينتقل التطبيق إلى تبويب الأخطاء عند وجود مشكلة.
4. يضغط `توليد MIPS` فتظهر IR العربية أولاً داخل تبويب IR، ثم ينتقل التطبيق تلقائياً إلى تبويب MIPS Assembly.
5. يضغط `حفظ ASM` لحفظ الملف وفتحه في محاكي MIPS.

## ملاحظة التوافق

تم الحفاظ على التسميات الداخلية الآمنة في MIPS، مثل `var_0` و`temp_0` و`while_0`. العربية تستخدم في العرض والتعليقات فقط، لأن ذلك يجعل تجربة المستخدم أفضل من دون الاعتماد على أسماء عربية داخل تعليمات المحاكي.

## إصلاح تداخل الشريط العلوي

تم تعديل الهيكل الجذري للنافذة من طبقات `DockStyle.Top` المتراكبة إلى `TableLayoutPanel` بأربعة صفوف ثابتة وواضحة:

| الصف | المحتوى |
|---|---|
| الأول | شريط الأوامر بارتفاع ثابت 48 بكسل. |
| الثاني | رأس الصفحة بارتفاع 70 بكسل. |
| الثالث | مساحة العمل المرنة التي تتمدد مع النافذة. |
| الرابع | شريط الحالة بارتفاع 26 بكسل. |

كما تم تحديد عرض كل زر، وزيادة ارتفاع الشريط، وتفعيل Overflow عند صغر النافذة. بذلك لا تتداخل عناوين الأوامر مع بعضها ولا تغطي الرأس أو محرر المصدر.

## اختبار الإصلاح

بعد البناء، شغّل التطبيق ثم اختبر نافذة بعرض كبير وآخر أصغر. يجب أن يبقى كل زر في صف واحد، وأن يظهر سهم Overflow عند عدم وجود مساحة كافية بدلاً من تداخل النصوص. كما يجب أن يبقى رأس الصفحة واضحاً، وأن تبدأ مساحة العمل أسفله مباشرة.
