# سجل تحقق نسخة LL(1)

**تاريخ التحقق في بيئة التطوير:** 23 أغسطس 2026.

## 1. نطاق التحقق

أضيفت إلى النسخة الحالية العناصر الآتية: محلل `Ll1Parser` قائم على Stack وجدول LL(1)، سجل خطوات قابل للعرض، جدول تحليل قابل للعرض، تبويبان في Windows Forms باسم «جدول LL(1)» و«تتبع LL(1)»، تشخيصات نحوية تذكر الرموز المتوقعة والرمز الفعلي، ومشغل اختبارات مستقل لقلب المترجم.

## 4. حد بيئة Linux

نجح بناء **قلب المترجم** داخل مشروع اختبار مستقل يستهدف .NET 8 ويضم Lexer وLL(1) وAST وSemantic وIR وMIPS. كما نجح مشروع فحص مستقل في تجميع `MainForm.cs` ومصادر التطبيق بمراجع Windows Forms، لذلك تم التحقق من صحة C# للتبويبات الجديدة. أما تشغيل الواجهة الرسومية نفسها فهو خاص ببيئة Windows وVisual Studio 2022.

أظهر التحقق التشغيلي مشكلة توافق مهمة في SPIM: التعليقات العربية المباشرة داخل ملف ASM قد تمنع بدء التنفيذ. لذلك أصبح مولد MIPS يكتب ملفاً ASCII فقط؛ أسماء المصدر العربية تبقى في IR والواجهة، والنصوص العربية تتحول إلى بايتات UTF-8 في توجيه `.byte`. بعد الإصلاح شغّل SPIM ملف عينة المجموع وأظهر `15` ثم أنهى التنفيذ بنجاح.

قبل التسليم النهائي، يجب تنفيذ **Build → Rebuild Solution** من Visual Studio 2022 على Windows، ثم فتح عينتي `09_ll1_precedence_test.bayan` و`10_ll1_missing_semicolon.bayan` كما يوضح دليل الاختبار.
