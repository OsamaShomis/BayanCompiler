# نظام تصميم Compiler Journey لمحرر بيان

## الفكرة

يتحول المحرر من سطح عمل مزدحم إلى رحلة ترجمة. لا يرى المستخدم سوى مرحلة واحدة في مساحة المحتوى: **المصدر** أولاً، ثم Tokens، جدول LL(1)، التتبع، شجرة التحليل، جدول الرموز، TAC، MIPS، أو التشخيصات. لا توجد أعمدة نتائج جانبية ولا تبويبات متنافسة.

## بنية الشاشة

كل شاشة من المحرر تستخدم أربعة صفوف فقط داخل `TableLayoutPanel` رئيسي:

| الصف | الارتفاع | المحتوى |
| --- | --- | --- |
| هوية المنتج | 64px | اسم بيان، اسم الملف أو حالة الجلسة، والهدف MIPS. |
| أوامر المهمة | 56px | فتح، حفظ، تحليل وترجمة، وحفظ MIPS عند توفره. |
| محتوى المرحلة | مرن | محرر المصدر أو artifact حقيقي واحد من CLI. |
| مسار الرحلة | 64px | أزرار مراحل متسلسلة وسابق/التالي. |

لا يعتمد هذا التخطيط على `SplitContainer` أو `TabControl` مرئي أو `Dock` متنافس داخل المساحة نفسها. حاوية المحتوى تستضيف عنصراً واحداً فقط في كل مرة.

## رموز التصميم

| الرمز | القيمة | الاستخدام |
| --- | --- | --- |
| Navy | `#18344D` | الهوية، العناوين، زر الترجمة الرئيس. |
| Paper | `#FBF8F2` | خلفية التطبيق ومساحة القراءة. |
| Sand | `#EDE3D7` | فصل المناطق وشريط مراحل الرحلة. |
| Copper | `#BE7E4F` | التمييز المحدود للهوية والمرحلة الحالية. |
| Ink | `#282D31` | النص الأساسي والكود العربي. |
| Success | `#236B4A` | نجاح CLI أو الوصول إلى MIPS. |
| Warning | `#9A6700` | تنبيه أو مرحلة غير مكتملة. |
| Error | `#B42318` | تشخيصات أو تعذر تشغيل CLI. |

## الخطوط والمقياس

يستخدم النص العربي `Segoe UI`، بحجم 11pt للمحتوى و13–18pt للعناوين. تستخدم TAC وMIPS خطوط `Cascadia Mono` أو `Consolas` بحجم 10.5–11pt. تعتمد الواجهة شبكة 8px: 24px حافة خارجية، 16px بين المجموعات، و12px داخل أسطح المحتوى.

## حالات الواجهة

| الحالة | ما يراه المستخدم | ما يحدث للتفاعل |
| --- | --- | --- |
| قبل الترجمة | محرر مصدر ومرحلة «المصدر» فعالة. | زر الترجمة متاح؛ النتائج الأخرى تقرأ رسالة فارغة واضحة. |
| تشغيل CLI | نص «يجري تشغيل CLI المستقل…» وشريط تقدم متحرك. | تعطيل فتح/حفظ/ترجمة وتصفح المراحل لمنع طلبات متزامنة. |
| نجاح | شارة نجاح باسم مرحلة الإنهاء، وانتقال إلى المصدر أو MIPS حسب الأمر. | تصبح المراحل التي تحتوي artifacts قابلة للاختيار. |
| فشل لغوي أو نحوي | شارة خطأ وانتقال مباشر إلى التشخيصات. | تبقى النتائج المكتوبة قابلة للقراءة، ويعود زر الترجمة متاحاً. |
| تعذر CLI | رسالة `EDITOR001` مفهومة مع تلميح لإعادة بناء الحل. | يبقى المصدر قابلاً للتحرير ولا تدّعي الواجهة أن الترجمة نجحت. |

## إمكانية الوصول

كل زر يحمل نصاً واضحاً لا يعتمد على رمز أو لون فقط، ويعرض `ToolTip` و`AccessibleName`. تظل حالة التركيز مرئية، وتبقى ألوان الخطأ والنجاح مصحوبة بنص. لا تتجاوز النصوص العربية المساحة؛ تستخدم العناوين المرنة والقطع الآمن أو التفاف النص بدلاً من العرض الثابت.
