# مترجم لغة «بيان» (Bayan Compiler & IDE)

مشروع مترجم تعليمي متكامل للغة البرمجة العربية **«بيان»** مبني باستخدام C# و .NET Windows Forms، ويغطي المراحل التسع الرسمية لخط إنتاج المترجم وفق متطلبات المادة الأكاديمية:

```
المصدر (01) ➔ الرموز Tokens (02) ➔ شجرة الإعراب Parse Tree (03) ➔ جدول الرموز (04) 
➔ التحليل الدلالي (05) ➔ الكود الوسيط TAC (06) ➔ لغة التجميع Assembly (07) 
➔ قائمة الأخطاء (08) ➔ نتيجة التنفيذ Console Output (09)
```

---

## 🚀 كيفية تشغيل المشروع لفريق العمل (Quick Start)

### 1. المتطلبات الأساسية
- حزمة **.NET SDK** (الإصدار 6.0 أو 8.0 أو 9.0 فما فوق).
- بيئة تطوير: **Visual Studio 2022** (مع خيار *.NET desktop development*) أو **VS Code** مع C# Dev Kit.

### 2. استنساخ المشروع (Clone)
```bash
git clone <رابط المستودع هنا>
cd BayanCompiler
```

### 3. البناء والتشغيل عبر سطر الأوامر (CLI)
- **تشغيل واجهة المترجم الرسومية (IDE):**
  ```bash
  dotnet run --project src/BayanCompiler
  ```
- **تشغيل أداة المترجم النصية (CLI):**
  ```bash
  dotnet run --project src/Bayan.Compiler.Cli -- samples/01_valid_program.bayan
  ```
- **تشغيل الاختبارات الآلية (25 اختبار):**
  ```bash
  dotnet test
  ```

### 4. التشغيل عبر Visual Studio 2022
1. افتح ملف الحل `Bayan.sln`.
2. اضغط بالزر الأيمن على مشروع `BayanCompiler` واختر **Set as Startup Project**.
3. اضغط `F5` لتشغيل واجهة IDE.

---

## 🎨 ميزات بيئة التطوير (IDE)
- **محرر كود متطور:** ترقيم الأسطر، تظليل مرئي للكلمات المحجوزة والأنواع والأرقام والنصوص، ومعلومات السطر والعمود.
- **التنقل المباشر بين المراحل الـ 9:** بنقرة زر واحدة للوصول الفوري لكل مرحلة من مراحل الترجمة.
- **طرفية تنفيذ تفاعلية (Terminal):** تشغيل الملف التنفيذي `output.exe` مباشرة، مع إمكانية إدخال القيم لتعليمة `اقرأ` وعرض زمن التنفيذ.
- **دعم النمطين الداكن والفاتح (Dark / Light Theme).**
- **أمثلة برمجية جاهزة للاختبار الفوري:** برامج صحيحة، حلقات، شروط، وحالات الأخطاء اللغوية والنحوية والدلالية.
